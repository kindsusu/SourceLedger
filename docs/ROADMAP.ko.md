# 제한된 범위의 자율 수집 로드맵

[English](ROADMAP.md) | [한국어](ROADMAP.ko.md)

첫 설정 후 출처 탐색·수집·근거 검증·이력 저장을 자동으로 진행하고, 인증 갱신과 판정할 수 없는 자료만 예외로 알리는 것이 목표입니다. 없는 가격을 추정하지 않습니다.

## 확정한 방향

- 첫 실행에서 산업군·상품·조사 시장을 입력합니다. 분석 목적은 받지 않습니다.
- 기본 안내·문서는 영어이며 한국어를 함께 제공합니다.
- SQLite와 원문 근거를 기준으로 저장하고 XLSX로 검토합니다. CSV 출력·ERP 연결은 범위에 넣지 않습니다.
- 유료 MCP·검색·모델 서비스를 자동으로 활성화하지 않습니다.
- 검색 후보, 수집 규칙 초안, 검증한 가격을 구분합니다.

## 진행 순서

1. **첫 실행 조사 공간:** 조사 주제, 알려진 식별자, 출처 후보, 다음 필요 작업을 보존합니다. 기존 정확 수집 설정과 분리합니다.
2. **출처 후보 탐색:** 지정 시작 URL과 선택적으로 연결한 검색 서비스를 사용합니다. 검색 요약의 가격을 확정값으로 쓰지 않습니다.
3. **규칙 검증·활성화:** 수집 설정을 실제 원문과 알고 있는 상품 조건으로 시험합니다. 통과한 버전만 활성화하고, 규칙·상품 조건이 바뀌면 기존 검증을 무효화합니다.
4. **상황에 따른 수집:** 새로운 페이지나 변경된 규칙을 다루는 모델 실행 루프를 추가합니다. 검증된 규칙은 이후 일반 코드로 재사용합니다.
5. **운영:** 예약 실행, 재시작 복구, 모델·브라우저 비용 제한, 예외 알림을 추가합니다.

## 완료 확인

초기 입력에서 분석 목적·비밀값을 요구하지 않고, 미연결 검색·모델은 실제 호출 없이 상태를 알립니다. 후보 발견은 활성 설정을 수정하지 않으며, 식별자·표본·원문 검증에 실패한 규칙은 활성화하지 않습니다. 기존 수집·재개·엑셀 기능의 회귀 시험과 통제된 통합 시험을 통과해야 합니다. 실사이트 성공률은 해당 사이트를 실제 확인한 경우에만 보고합니다.

이 문서는 단계별 개발 계획이며, 모든 자율 기능이 이미 구현됐다는 뜻은 아닙니다.
