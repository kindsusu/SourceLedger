# 제한된 범위의 자율 수집 로드맵

[English](ROADMAP.md) | [한국어](ROADMAP.ko.md)

## 목표

초기 설정 뒤 SourceLedger가 관련 출처를 찾고, 근거를 수집·검증하고, 이력을 보존하도록 만듭니다. 인증 갱신과 실제로 판정할 수 없는 자료만 명시적 예외로 남깁니다. 없는 가격은 추정하지 않습니다.

## 확정한 방향

- 기본 인터페이스·보고서 언어는 영어입니다. 한국어 온보딩·문서는 제공하지만 XLSX 전체 한국어 현지화는 아직 구현하지 않았습니다.
- SQLite와 원문 근거를 기준으로 저장하고 XLSX로 검토합니다. CSV 출력·ERP 연결은 범위 밖입니다.
- 유료 MCP·검색·모델 서비스를 자동으로 켜지 않습니다.
- 검색 후보, 설정 초안, 검증 receipt, 확인 가격 관측은 별도 객체입니다.

## 단계

1. **첫 실행 조사 워크스페이스 — 구현됨.** 산업군, 대표 상품 하나, 시장, 식별자, 승인 후보를 영문 또는 한국어로 저장합니다. 일반 수집 설정은 분리되어 있고 여러 상품을 지원합니다.
2. **제한된 출처 탐색·초안 — 구현됨.** 후보를 보존하고 HTTP/브라우저 fallback으로 같은 호스트 링크를 탐색합니다. 선택적으로 설정한 SearXNG에서 검색하며 결과는 발견 근거가 있는 후보로 저장합니다. 초안은 명시 식별자·후보에서 만듭니다.
3. **검증·활성화 — 구현됨.** 정확한 설정과 보존 근거를 검증하고, 필요하면 known sample을 대조하며, 변경되지 않고 통과한 설정만 활성화합니다. 로컬 receipt는 감사 기록이지 서명은 아닙니다.
4. **규칙 제안·제한 실행 — 0.3 구현됨.** 구조화된 데이터·의미가 명시된 HTML 규칙, 선택적 로컬 Ollama 선택자 제안, 출처별 진행 저장, 새 통합 수집 검증, 정답 표본 기반 선택적 활성화를 제공합니다. 브라우저 동작 계획·규칙 변경 복구·실제 모델 평가는 남아 있습니다.
5. **운영·클라이언트 전달 — 미구현.** 예약 실행, 재시작 복구, 모델·브라우저 한도, 예외 알림, 클라이언트 UI 검증, 통제된 배포를 추가합니다.

## 다음 단계 완료 기준

- 설정한 검색 제공자는 명시적 한도와 출처·수집시각 기록을 갖고, 미설정 제공자는 네트워크 호출을 하지 않습니다.
- 제안 규칙은 정확한 근거와, 제공된 경우 known sample을 통과하기 전까지 활성 수집 설정을 바꾸지 못합니다.
- 무인 운영을 주장하기 전에 대표 실제 사이트에서 추출 정확도, 접근 결과, 브라우저 fallback 동작을 측정합니다.
- 예약·에이전트 동작에는 시간·브라우저·모델 비용 한도와 조치 가능한 실패 기록이 있습니다.

다음 우선순위는 대표 실사이트와 설정한 공급자 검증, 통제된 규칙 복구와 운영입니다. 범위가 정해진 실행 제어기는 제공하지만 제한 없는 자율 운영을 보장하지 않습니다.
