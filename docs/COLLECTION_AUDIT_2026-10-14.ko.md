# 사이트 공통 수집 검토

사이트 수집의 완료 여부는 작업 종료, 상품 발견 범위, 가격·옵션 추출 범위, 개별 값 검증 상태로 구분합니다. 전체 목록 끝을 증명할 수 없으면 `범위 확인 불가`로 표시합니다.

## 공통 점검 항목

- 상품 링크·JSON-LD·옵션 배열의 안전 한도가 잘렸는지 기록합니다.
- 페이지의 각 가격과 조건을 최종 원본 및 SQLite 관측값과 대조합니다.
- 더보기, 필터, 페이지 이동, 숨은 카드의 확인 범위를 별도로 기록합니다.
- 주소 규칙이 바뀌어도 사이트별 경로가 발견과 추출에서 일치하도록 유지합니다.
- 오류·차단·미완료 페이지는 성공한 페이지와 구분하고 근거를 남깁니다.

## 검증

실제 업체 수집 건수나 시간은 공개 문서에 고정하지 않습니다. 합성 fixture로 가격 기간, 옵션, 한도 초과, 빠진 링크, 부분 범위 상태를 재현하고 승인된 실사이트 검증은 Git 제외 로컬 작업 공간에 보관합니다.
