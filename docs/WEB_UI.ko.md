# 브라우저 UI

[English](WEB_UI.md) | [한국어](WEB_UI.ko.md)

SourceLedger 0.5는 기존 연구 워크스페이스, 지속 작업, SQLite 원장, XLSX 보고서를 사용하는 로컬 브라우저 인터페이스를 추가합니다. 한 대의 PC에서 SourceLedger를 시작하는 가장 쉬운 방법입니다. 자동화와 고급 작업에는 기존 CLI와 Codex·Claude 로컬 MCP 연결을 계속 사용할 수 있습니다.

## 시작

저장소 core를 설치한 뒤 인수 없이 실행합니다.

```bat
setup.cmd
source-ledger.cmd
```

PowerShell에서는 `.\setup.cmd`와 `.\source-ledger.cmd`를 사용합니다. macOS/Linux에서는 다음과 같습니다.

```bash
bash setup.sh
bash source-ledger.sh
```

launcher는 `http://127.0.0.1:8765`를 열고 현재 checkout 아래 `.sourceledger`를 사용합니다. 설치 방식에 맞는 명시적 명령을 사용할 수 있습니다.

```text
source-ledger ui
.\source-ledger.cmd ui
bash source-ledger.sh ui
```

사용 가능한 옵션:

```text
--workspace-root PATH   다른 로컬 워크스페이스 디렉터리를 사용합니다.
--port PORT             다른 loopback 포트를 사용합니다. 기본값은 8765입니다.
--no-browser            브라우저 탭을 열지 않고 서버만 시작합니다.
```

기본 설치만으로 UI를 사용할 수 있습니다. Playwright 수집이 필요하면 `setup.cmd --browser`, Codex·Claude 연결이 필요하면 `setup.cmd --mcp`를 실행하세요. 두 옵션을 함께 사용할 수도 있습니다. 운영체제별 내용은 [설치 안내](INSTALLATION.ko.md)를 참고하세요.

## 언어

상단 **언어** 선택기에서 **English**, **한국어**, **日本語**를 선택할 수 있습니다(영어에서는 **Language**, 일본어에서는 **言語**). 기본값은 영어입니다. 선택은 해당 로컬 UI origin의 브라우저 `localStorage`에 저장되어 같은 UI로 돌아왔을 때 유지됩니다. 전환은 새로고침 없이 적용되며 현재 입력값과 체크박스 선택을 보존합니다. UI 레이블, 상태 문구, 현지화된 날짜 표시 형식만 바뀝니다. 저장된 출처 내용·증거·가격·모델 ID·MCP 설정·연구 워크스페이스 언어·보고서 데이터는 번역하거나 변경하지 않습니다. AI 번역을 수행하거나 외부에 요청하지 않습니다.

## 처음 사용

1. **Research plan**에 짧은 요청이나 여러 줄의 상세 요청을 입력합니다. 상품 변형, 제외 범위, 상업 조건도 원문 요청에 남깁니다.
2. 기본 경로는 이 화면에서 제한된 AI 미리보기를 실행합니다. **Connections**에서 설치된 Codex CLI·Claude Code CLI 공급자와 모델을 설정한 뒤 **Preview research plan** 버튼을 누르세요. 화면을 열기만 해서는 공급자를 호출하지 않습니다. 연결된 AI 앱의 검색 도구와 MCP 제출은 선택할 수 있는 보조 경로입니다. 근거 URL은 출처 후보이며 가격 관측이 아닙니다.
3. 미리보기를 검토하고 URL을 추가·제거하며 대상 페이지를 선택합니다. 산업군·상품·시장을 확인하세요. 정확한 식별자는 정밀 매칭을 위한 고급 입력이며 필수가 아닙니다. 수정할 때마다 계획 revision이 바뀝니다.
4. 표시된 계획 revision을 명시적으로 승인한 뒤 제한된 수집을 시작합니다. 이 작업의 worker는 자동으로 시작합니다. 선택 페이지와 제한된 같은 호스트 링크만 대상으로 하며 체크 해제·제외 URL은 수집하지 않습니다.
5. **Runs**에서 페이지 범위, 근거 상태, 누락값, 관측, XLSX 보고서를 확인합니다.

기존 안내형 연구 워크스페이스는 하나의 상품을 출발점으로 삼지만 새 연구 계획은 상품 범위를 기술할 수 있습니다. 이후 정확 수집 설정에는 여러 상품을 넣을 수 있습니다.

계획 UI는 `GET/POST /api/plans`와 `POST /api/plans/edit`, `/api/plans/preview`, `/api/plans/confirm`, `/api/plans/start`를 사용합니다. 패키지에 포함된 화면 파일은 `plan-ui.js`와 `plan-messages.js`입니다. UI 기본 언어는 영어이며 언어 선택기에서 한국어·일본어로 바꿀 수 있습니다. AI 미리보기는 상품 가격을 수집하지 않습니다. 승인한 revision은 수집 전 저장되고 이후 수정하면 다시 승인해야 합니다. 계획 수집은 원문 근거를 SQLite에, 보고서를 XLSX로 기록합니다. 알려진 사이트 어댑터와 일반 JSON-LD Product/Offer 기록을 지원하지만 임의 DOM 해석과 자연어 상업 조건의 의미 검증은 지원하지 않습니다. 화면 표시가 확인되지 않은 JSON-LD 가격은 검토·비교 제외 대상입니다. 알려진 어댑터의 가격도 계획 조건을 독립 검증하지 않았으므로 검토 대상입니다. 같은 호스트의 관련 없는 탐색 링크를 한도 안에서 방문할 수 있으며, 범위 기록은 방문·미처리 URL을 보여줄 뿐 전체 사이트의 완전성을 주장하지 않습니다. 없는 가격·통화·식별자·조건은 추정하지 않습니다.

## 화면 구성

### Research plan

계획은 요청 전문과 각 수정본을 보관합니다. 미리보기 후보의 URL·이유·근거 링크는 검토 자료이며 확인된 출처나 가격이 아닙니다. 시작 전에 대상을 선택·추가·제거하고 연구 주제를 수정할 수 있습니다. **Start this research**를 누르면 UI가 현재 수정본을 승인하고 제한된 수집을 대기열에 넣습니다. 결과 실행에서 범위 누락과 검토 표시를 확인하세요.

### Overview

최초 설정 상태, 연구 진행을 막는 항목, 출처 수, 최근 작업, worker 상태를 표시합니다. worker는 웹 서버와 독립적으로 대기 작업을 실행합니다. 브라우저 탭이나 UI 서버를 닫아도 worker가 이미 맡은 작업은 취소되지 않습니다. 필요할 때 worker를 별도로 중지하세요.

### Sources

고급 **Sources** 화면은 정확한 상품 식별자와 등록된 연구 출처를 관리합니다. URL을 입력하면 회사·사이트를 바로 등록하고, URL 없이 회사명만 입력하면 실제 사이트를 찾는 요청을 만듭니다. 키워드를 입력하면 관련 출처 추천 요청을 만듭니다. 요청 생성만으로 AI 클라이언트가 시작되거나 검색이 실행되지는 않습니다. CLI 실행을 원하면 **Run in web UI**를 명시적으로 선택합니다. 요청 문구를 연결된 Codex·Claude에 복사해 전달하면, 해당 AI가 사용 가능한 검색·브라우저 도구로 실제 URL을 찾고 이름·추천 이유·근거 URL을 제출할 수 있습니다. 검색이 불가능하거나 결과가 없으면 빈 후보 목록과 설명을 제출할 수 있습니다.

추천 후보는 등록된 출처 및 가격 관측과 별도로 보관합니다. 추천 이유와 근거 URL은 미검증 정보입니다. 후보를 검토해 체크박스로 원하는 출처만 추가하고, 나중에 더 요청하거나 추가할 수 있습니다. **Run in web UI**를 사용하려면 SourceLedger가 실행되는 컴퓨터에 Codex CLI 또는 Claude Code CLI를 설치하고 로그인해야 합니다. **Connections**에서 공급자, 공급자 기본값 또는 모델 ID, 타임아웃(30~600초, 기본 180초)을 설정하고 저장합니다. 설치 여부만 가능 상태에 반영되고 인증은 요청 실행 시 확인합니다. CLI 기본 인증과 계정 사용 조건이 적용됩니다. SourceLedger는 API 키를 저장하거나 CLI 설치·로그인을 하지 않고 공급자 자동 대체도 하지 않습니다. 이 설정은 열려 있는 데스크톱 대화의 모델을 바꾸지 않습니다. 요청을 명시적으로 실행하면 로컬 worker 작업으로 대기하며 가격 수집 작업은 시작하지 않습니다. 검색 중 공급자 CLI가 웹 페이지에 접근할 수 있습니다. 등록된 출처에서는 같은 호스트 내의 제한된 링크 발견과 추출 규칙 제안을 대기열에 넣을 수 있습니다. 이 결과도 확인된 가격 관측은 아닙니다.

기존 안내형 연구 경로에서는 등록된 출처를 체크박스로 선택합니다. UI는 선택한 출처 ID를 명시적으로 전달하며 최대 50개 출처, 120초 한도를 적용합니다. 이 연구 작업에는 worker가 필요하지만 요청 생성과 추천 후보 선택에는 필요하지 않습니다. 웹 UI 추천 실행은 선택한 CLI를 통한 명시적 외부 모델 호출입니다. 기존 수집 모델 호출은 계속 선택 사항이며 기본 한도는 0회입니다. 수동 AI 앱 인계 경로에서 SourceLedger 자체는 모델을 호출하지 않으며 호스트 앱의 요금제·도구 제한이 적용됩니다. 없는 가격·통화·식별자·상업 조건은 빈값으로 남깁니다.

### Runs

지속 작업의 실행 상태와 근거 품질을 분리해 표시합니다.

- `queued`, `running`, `interrupted`, `failed`, `succeeded`는 프로그램 실행 상태입니다.
- 실행이 성공해도 근거 상태는 `needs_review`, `ineligible`, `partial` 등 확인되지 않은 결과일 수 있습니다.

작업 상세에서는 한도가 있는 페이지 단위 관측과 등록된 XLSX 보고서 다운로드 링크를 볼 수 있습니다. 보고서는 SQLite 원장에서 생성합니다. 출처 문장과 관측값은 신뢰할 수 없는 데이터이며 도구 지시로 취급하지 않습니다.

고급 작업에는 설정 검증, 정확 수집 실행, 지원 사이트 수집, XLSX 내보내기가 있습니다. 지원 사이트 수집은 현재 구현된 어댑터의 명시적인 페이지를 대상으로 하며 사이트 전체 또는 실시간 재고 범위의 완전성을 주장하지 않습니다.

### Connections

Codex, Claude Code, Claude Desktop에 복사할 수 있는 로컬 설정을 만들고 Codex CLI·Claude Code CLI를 통한 웹 UI 추천 실행용 공급자·모델·타임아웃을 저장할 수 있습니다. 클라이언트 설정을 직접 수정하거나 열려 있는 데스크톱 대화의 모델을 바꾸지 않습니다. UI와 같은 워크스페이스 root를 사용하므로 최초 설정 데이터와 지속 작업 이력을 함께 볼 수 있습니다.

복사형 MCP 설정을 사용할 때는 MCP 의존성을 설치합니다. 웹 UI CLI 추천 기능에는 MCP가 필요하지 않습니다.

```powershell
.\setup.cmd --mcp
```

설정 대상과 고급 CLI 연결 절차는 [로컬 AI 도구 연결](ASSISTANT_CONNECTIONS.ko.md)을 참고하세요. Codex·Claude 클라이언트 GUI는 이 브라우저 UI와 별도이며 사용할 실제 환경에서 확인해야 합니다.

## 로컬 범위

웹 서버는 `127.0.0.1`에만 연결됩니다. 이번 범위에는 인증, 원격 웹 호스팅, 제3자 MCP 클라이언트, ChatGPT 웹·모바일 직접 연결이 포함되지 않습니다.

SourceLedger는 선택한 로컬 워크스페이스 안에서 동작합니다. 연구 워크스페이스, 데이터베이스, 증거, 브라우저 프로필, 자격증명, 생성 보고서는 Git에 커밋하지 않아야 합니다. 내부 출처에는 명시적인 권한이 필요하며 로그인이나 자격증명 입력을 자동화하지 않습니다.

## CLI도 계속 사용 가능

UI는 CLI와 로컬 assistant connector가 사용하는 워크스페이스·작업 구조를 그대로 사용합니다. 고급 사용자는 다음 명령을 계속 사용할 수 있습니다.

```powershell
.\source-ledger.cmd init --lang ko
.\source-ledger.cmd research-status
.\source-ledger.cmd source-add --url "https://authorized.example/product"
.\source-ledger.cmd product-set --identifier model=EXACT-MODEL
.\source-ledger.cmd assistant start --workspace-root .sourceledger
```

전체 CLI 연구 흐름은 [시작 안내](GETTING_STARTED.ko.md), 제한된 에이전트·검증·활성화·공급자 설정은 [자동화 안내](AUTOMATION.ko.md)를 참고하세요.
