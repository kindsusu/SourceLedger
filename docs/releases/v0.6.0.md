# SourceLedger 0.6.0

SourceLedger 0.6.0 improves evidence-preserving collection, makes incomplete coverage actionable, and adds bounded browser assistance for access challenges. SQLite remains the system of record and XLSX the human-readable report.

## Changes

- Optional browser process reuse and bounded browser concurrency for approved collection batches.
- Reviewed collection rules for options, pagination, load-more controls, and scrolling, with capture-level evidence and explicit incomplete coverage.
- Broader structured-data extraction and rental-condition handling without inventing missing prices or terms.
- Persistent collection issues, triage, reviewed follow-up plans, and evidence-backed revalidation through MCP, the web UI, and XLSX.
- Conservative access-challenge detection, retry suppression, and connected-browser assistance with durable reservations limited to two attempts per run and URL.
- Updated English and Korean documentation and English/Korean/Japanese interface messages.

## Verification and limits

- Windows/Python 3.12 headless suite: **613 passed, 1 skipped** in 573.45 seconds. The skip covers a Unix-specific virtual-environment symlink case.
- The final HTTP-to-browser challenge coverage fix passed **26 related regression tests** after the full suite; counts overlap and are not additive. Safe HTTP observations remain available while later browser blocking creates a recovery issue, including checkpoint reanalysis.
- A stale installed-MCP smoke assertion was updated to check required capabilities rather than an obsolete fixed tool count. Installed-wheel smoke checks cover local verification, SQLite/XLSX, the independent MCP worker, and the web interface.
- Research data and browser credentials are excluded from both source control and distribution archives.

One authorized checkbox attempt in Google's official reCAPTCHA demo passed in the connected Codex browser, and ordinary form submission returned the server's success message. No image puzzle appeared and no paid API was used. Jetcar and Gongcar did not present a CAPTCHA. The demo is not a blocked-product recovery benchmark.

There is no built-in CAPTCHA solver or automatic transfer of the AI browser session into the server collector. End-to-end recovery on a genuinely blocked product site, image/audio challenges, and Claude browser hosting remain unverified. Unknown sites, custom widgets, and virtualized catalogs can still require a reviewed recipe and operator assistance. Missing evidence never establishes completeness.

## Installation

The release includes a Python wheel and source distribution. Python 3.11 or later is required. The source archive includes the portable setup scripts; follow the [installation guide](https://github.com/kindsusu/SourceLedger/blob/v0.6.0/docs/INSTALLATION.md) or [Korean guide](https://github.com/kindsusu/SourceLedger/blob/v0.6.0/docs/INSTALLATION.ko.md). Browser and MCP dependencies are optional. No hosted service, subscription account, paid API key, research database, browser profile, or collected report is bundled.
