# SourceLedger 1.0.0

Version 1.0.0 establishes a clean public source history from the reviewed SourceLedger code. This is a repository and distribution maintenance release: the collection workflow, web UI, MCP tools, SQLite storage format, and XLSX output remain the same. Existing research databases, evidence files, and reports stay in their local workspaces; no data migration is required.

The former public history and release archives were retired to remove research-specific material from the current GitHub publication. Existing source clones must be freshly cloned, or have their Git metadata reset to the new `main` history. Preserve local research workspaces and configuration before replacing a checkout. Old commit hashes and release download URLs no longer identify this version.

Install Python 3.11 or later (Python 3.12 recommended) and follow the [installation guide](https://github.com/kindsusu/SourceLedger/blob/v1.0.0/docs/INSTALLATION.md) or [Korean guide](https://github.com/kindsusu/SourceLedger/blob/v1.0.0/docs/INSTALLATION.ko.md). The wheel and source distribution contain the application, not research databases, collected evidence, credentials, browser profiles, or generated reports. Browser and MCP dependencies remain optional. Source attribution and license notices remain in the repository.

Release verification is tracked by the [CI and verified release procedure](https://github.com/kindsusu/SourceLedger/blob/v1.0.0/docs/CI_RELEASE.md). This note does not claim an outcome for checks that are still running.
