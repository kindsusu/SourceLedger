# SourceLedger 1.0.1

Completed collections now generate one final XLSX workbook and a standalone HTML dashboard linked to that workbook. Both are available from the local web UI and MCP. The dashboard supports English, Korean, and Japanese and summarizes recorded results, source sites, available categories or included data, and collection coverage. Unmeasured accuracy remains explicitly unmeasured.

Batch finalization preserves source values, evidence links, styles, and run metadata. Only the current batch journal's runs are included. Export failures can be retried without recollecting completed batches, and resuming a single run can restore its dashboard. Cached sheet metadata reduces repeated work during merging.

Existing SQLite data and local evidence remain unchanged; no data migration or model API is required. Keep the HTML and XLSX together when moving the final files. Batch workbooks remain available for recovery and inspection. Restart the local web UI and reconnect the MCP server after updating to load the new code and tools.

Distributions are published through Verified release from the exact commit's successful main CI artifacts, covering Windows, macOS, Linux, and package installation. Generated reports and research data are excluded from the release.

## 한국어

수집 완료 시 최종 XLSX 하나와 해당 파일을 연결한 HTML 대시보드가 자동 생성됩니다. 웹 UI와 MCP에서 접근할 수 있고, 대시보드는 영어·한국어·일본어를 지원합니다. 기록된 결과·출처·확인 가능한 분류 또는 포함 데이터·수집 범위를 표시하며, 측정하지 않은 정확도는 미측정으로 표시합니다.

배치 병합은 현재 실행의 결과만 포함하고 원본 값·근거 링크·서식·실행 정보를 보존합니다. 최종 파일 생성 실패는 완료된 배치를 재수집하지 않고 다시 시도할 수 있습니다. 시트 정보를 재사용해 병합의 반복 작업도 줄였습니다.

기존 SQLite·로컬 증거는 유지되며 데이터 이전이나 모델 API가 필요하지 않습니다. 최종 파일을 이동할 때 HTML과 XLSX를 함께 옮기세요. 배치별 파일은 복구·검토용으로 보존됩니다. 업데이트 후 웹 UI를 재시작하고 MCP를 다시 연결하면 새 코드와 도구가 적용됩니다.

정확한 릴리즈 커밋의 Windows·macOS·Linux·패키지 검사가 통과한 배포 파일을 Verified release로 발행합니다. 조사 자료와 생성 보고서는 배포에 포함하지 않습니다.
