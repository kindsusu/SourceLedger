# 수집 시간 측정과 최적화

목록 탐색, 수집, 근거 검수, AI의 판단·도구 호출 시간을 따로 측정합니다. 속도가 빨라져도 URL·상품 조건·가격 근거·누락 검사가 같아야 유효한 개선입니다.

## 2026년 10월 측정

기존 `collect_plan` 수집기를 직접 호출해 작업자 2개, 20 URL 배치, 서로 다른 저장 디렉터리로 실험했습니다. 매번 새 HTTP·브라우저 수집을 실행하고 SQLite·근거·XLSX를 저장했습니다. 모델 API나 AI CLI는 사용하지 않았습니다. **MCP의 중단 복구 체크포인트는 이번 실험에서 사용하지 않았으므로 기본 MCP 실행 시간이나 정식 병렬 기능의 성능이 아닙니다.**

동일한 7개 URL은 작업자 1개에서 22.50초, 2개에서 18.49초로 **17.8% 단축**됐습니다. 가격·조건·근거 방식 25행이 동일했습니다. 한 번의 소규모 비교이며 모든 사이트에 적용되는 보장 수치는 아닙니다. 확대 실행 490 URL은 1,166.58초였습니다. HTTP 작업 시간 합계는 393.72초, 브라우저는 1,780.20초입니다. 병렬 실행이므로 이 합계를 실제 경과시간으로 표시하면 안 됩니다.

한달·하루렌트는 목록과 상세를 구분합니다. 한달렌트의 계약기간별 가격은 별도 관측이며 목록의 시작 가격을 추가 상품으로 중복 집계하지 않습니다. 목록은 사이트 선언 수와 추출 수가 일치해야 완료입니다. 스크롤로 로딩되는 목록은 `scroll` 확장 방식을 사용합니다. 클릭하면 새로 나타난 상품을 잘못 누를 수 있습니다. 총수나 확장 완료 근거가 없으면 완료로 판단하지 않습니다.

## 구독형 AI 앱의 요청부터 최종 답변까지 비교 (2026-10-13)

ChatGPT 구독으로 로그인한 Codex CLI 한 세션이 각 방식에서 계획 생성·수정·확인, 수집 시작·완료 대기·결과 확인, 한국어 최종 답변까지 직접 진행했습니다. 사용 모델은 현재 설정된 `gpt-6-astra`, 추론 수준은 medium이며 모델 API 키를 쓰지 않았습니다. 순차는 MCP 작업 공간 1개, 병렬은 AI 세션 하나가 독립된 MCP 작업 공간 2개를 맡았습니다. ## 적용 우선순위

1. **제한된 병렬 수집:** 같은 목록·체크포인트·캐시·스크린샷 조건에서 작업자 1개와 2개를 비교합니다. 도메인별 호출 간격, 재시도, 취소, 중단 복구 예산을 유지합니다. 차단이나 과도한 요청 응답이 나타나면 동시 수를 늘리지 않습니다.
2. **브라우저 재사용:** 작업자별 브라우저 프로세스를 유지하고 페이지마다 새 격리 컨텍스트를 만듭니다. 매번 시작하는 비용의 절감 폭은 아직 독립 측정하지 않았습니다. 프로필 분리·장애 복구·근거 보존을 검증해야 합니다.
3. **체크포인트 저장 개선:** 근거 파일은 한 번 저장하고 작은 진행 상태만 갱신합니다. 현재는 누적된 캡처와 바이너리를 매번 직렬화합니다. 구버전 읽기, 원자성, 중단 페이지의 예산 차감과 복구를 보존해야 합니다. 스크린샷을 제외한 7개 캡처 재생은 체크포인트 없이 1.76초, 사용 시 3.14초였습니다. 운영 환경 절감률로 환산하지 않습니다.
4. **중복 작업 줄이기:** 한 상세에 계약기간별 가격이 모두 보이면 한 번에 읽습니다. 변경 없는 근거의 재사용은 신선도·조건부 응답을 확인한 경우에만 허용합니다. 속도만을 이유로 HTTP나 브라우저를 생략하지 않습니다.
5. **전체 흐름 측정:** 수집 단계, 모델 판단, 도구 호출, 실제 제공된 토큰 사용량을 분리합니다. 앞선 수집기 직접 호출·MCP 직접 호출 실험에는 모델 추론 단계가 없었지만 위 구독형 AI 실험에는 모델 조정 시간이 포함됩니다. 제공되지 않은 단계별 토큰 수는 추정값으로 채우지 않습니다.

## 완료 기준

- 고정 URL 목록과 조회 조건을 비교하고 사이트 상품 변동은 따로 기록합니다.
- 행 수뿐 아니라 가격·조건 집합, 선언 수·관측 수·추출 수, 근거 방식도 대조합니다.
- HTML·receipt·스크린샷과 해시를 확인하고, 상업 조건이 불완전하면 검토 상태를 유지합니다.
- 성공 수집 시간, 실패·재시도 비용, 개발·검수 시간을 분리합니다. 나눠 실행한 시간 합계는 단일 연속 실행 시간으로 표현하지 않습니다.
- 이전과 범위·설정이 다른 실행으로 정확한 개선율을 주장하지 않습니다.

상품 목록·가격·데이터베이스·근거 파일은 Git에서 제외된 로컬 작업 공간에 보관합니다.
