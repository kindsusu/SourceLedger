# 구현 상태

2026-09-17 버전 0.3 Windows 전체 테스트: **110 passed** (`python -m pytest tests -q`). 통제된 검색 응답에서 시작하는 에이전트 흐름, 실제 로컬 HTTP 수집, 규칙·모델 응답 검증, 한도·재개·설정 변경 거절·정답 표본 기반 활성화를 확인했습니다. 실제 SearXNG/Ollama 서버·모델은 설치하거나 호출하지 않았습니다.

0.2 기준선은 74개였습니다. 기존 로컬 브라우저 동작, MCP 연결 종료 후 작업 지속, XLSX 검증도 포함됩니다. HTTP 차단 뒤 브라우저 전환은 모의 차단 테스트이며 실사이트의 차단 복구를 입증하지 않습니다.

[English](STATUS.md) | [한국어](IMPLEMENTATION_STATUS.md)

SourceLedger 0.3은 근거 우선 수집과 범위가 정해진 연구 실행을 제공합니다. 임의 웹을 스스로 탐색·판단하는 무제한 자율 에이전트는 아닙니다.

## 구현됨

- **조사 워크스페이스:** `init`은 산업군·대표 상품·조사 시장을 받는 영문/한국어 첫 실행 워크스페이스를 만듭니다. 명시 식별자, 승인된 같은 호스트의 출처 후보, 준비 상태와 다음 작업을 저장합니다. 분석 목적·비밀값은 받지 않습니다. 현재 워크스페이스는 대표 상품 하나를 대상으로 하며, 일반 수집 설정은 여러 상품을 지원합니다.
- **제한된 후보 탐색:** 저장한 후보 출처 하나에서 최대 개수만큼 같은 호스트 링크를 찾습니다. HTTP를 먼저 시도하고 차단되거나 사용할 수 없으면 설정된 브라우저 fallback을 사용합니다. 결과는 후보일 뿐 가격·활성 출처·추출 규칙으로 자동 전환되지 않습니다.
- **초안·검증·활성화 통제:** 명시 식별자가 있는 워크스페이스에서 설정 초안을 만들 수 있습니다. `verify`는 정확한 설정과 보존 근거를 검사하며, 선택적 known sample이 있으면 상품·가격의 독립 대조도 추가합니다. `activate`는 통과한 정확한 설정과 근거만 받습니다. 설정 변경, 근거 누락·변조·만료, 상품 배정 누락, known sample 불일치는 거절합니다. receipt는 로컬 감사 기록이며 서명된 증명서는 아닙니다.
- **기존 수집 엔진:** 명시 상품 식별자, 출처 URL/파일, 추출 규칙, HTTP/파일 수집, 선택적 Playwright 브라우저 동작과 선택적 Crawl4AI adapter를 제공합니다.
- **근거·검증:** 원문 바이트, 로케이터, 수집 시각, SHA-256을 보존하고 상품·가격·통화·규격·상업 조건을 엄격히 검사합니다. 가격이 없으면 빈칸으로 남깁니다.
- **저장·보고:** SQLite 실행 이력, 재개 가능한 작업, 근거 파일과 6개 시트 XLSX 보고서를 제공합니다. 보고서 기본 표기는 영어이며, 온보딩과 문서는 한국어도 제공합니다.
- **로컬 MCP 운영:** MCP는 독립 worker에 고정 설정 작업을 등록합니다. 조사 워크스페이스·후보는 활성 `run` 설정과 분리되어 있으며, 설정된 수집은 activate 없이도 실행할 수 있습니다.
- **키워드 검색:** 선택적 SearXNG JSON API를 한 번 호출하고 URL 필터와 후보 발견 근거를 저장합니다. 명시적인 공급자 설정이 없으면 검색 호출은 0회입니다.
- **규칙 제안:** 구조화된 데이터·의미가 명시된 HTML의 추출 규칙과 선택적 로컬 Ollama 선택자 제안을 지원합니다. 실제 DOM·식별자·근거를 확인하고 부족한 조건은 비워 둡니다.
- **실행 제어:** `agent`는 출처별 진행과 범위·한도를 저장하고 재개합니다. 출처별 제안 후 전체 출처를 한 번에 새로 수집해 공통 SQLite와 XLSX에 기록합니다. 자동 활성화는 모든 선택 출처·상품의 정답 표본이 있을 때만 가능하며 불완전한 출처도 결과에 남습니다.

## 검증 범위

기존 수집 기준선은 Windows/Python 3.12에서 **44개 테스트 통과**였습니다. 로컬 Chrome 동작, 근거 캡처, stdio MCP, MCP 연결 종료 뒤 worker 수집 지속, XLSX 렌더링을 포함합니다. 이 수치는 과거 기준선이며 현재 통합 전체 테스트 수를 뜻하지 않습니다.

현재 통합 시험은 첫 실행 워크스페이스, 영문/한국어 입력, 저장 후보, 브라우저 fallback을 포함한 같은 호스트 bounded 탐색, 설정 초안, 검증 receipt, 선택적 known sample, 변경·누락 근거의 활성화 거절을 다룹니다. known sample은 선택 사항입니다. 없을 때 `verify`는 설정·근거 무결성을 검사하지만 독립적인 가격 정답 대조를 주장하지 않습니다.

데모 값은 합성 자료이며 시장 가격이 아닙니다. 실제 사이트의 정확도·접근 성공률·브라우저 복구는 대상 사이트에서 별도로 측정해야 합니다.

## 미구현 또는 미검증

- 실제 SearXNG/Ollama 서버와 모델 검증. 현재 공급자 테스트는 통제된 HTTP 응답을 사용
- 임의 브라우저 동작 계획, 레시피 복구, 기존 규칙의 무인 자동 복구
- 예약 실행, 서비스 배포, 알림과 상시 무인 운영
- Claude/ChatGPT 클라이언트 UI 연결 및 원격 산출물 전달 검증
- 대표 실제 사이트 수집 평가
- 스캔 PDF OCR, ERP 연결, CSV 출력, 분석·모의계산 기능

Crawl4AI는 선택 기능이며 이 환경에서 실사이트 검증을 하지 않았습니다. Agent-Reach는 진단·라우팅 설계 참고이고 직접 런타임 의존성은 아닙니다. ego-lite는 Windows에 직접 연동하지 않았습니다. UCP, commerce-agents, insane-search, 유료 Ultimate Web Scraper MCP는 설계 참고 또는 미연결 서비스입니다.

0.3 명령과 연결 준비는 [자동화 안내](AUTOMATION.ko.md)를 참고하세요. 전체 시간 한도는 요청별 타임아웃을 사용하는 방식이며 프로세스 강제 종료를 보장하지 않습니다. Ollama는 클라우드 기능을 꺼야 하며 루프백 주소만으로 서버 동작을 보증하지 않습니다.
