# 0.3 단계: 범위가 정해진 연구 실행

[English](MILESTONE_03.md) | [한국어](MILESTONE_03.ko.md)

목표는 0.2의 원문 검증을 유지하면서 출처 URL 탐색과 첫 추출 설정의 수작업을 줄이는 것입니다.

범위:

- 명시적으로 설정한 SearXNG JSON 검색 연결, 호출 제한과 후보 발견 근거 저장
- 구조화된 데이터·의미가 명시된 HTML을 이용한 규칙 제안, 선택적 로컬 Ollama 보조. 모델은 선택자만 제안하고 가격값이나 실행 동작은 만들지 않음
- 출처별 진행 저장·재개, 호출 한도, 제안 설정 검증, 정답 표본이 있는 경우 선택적 활성화
- 영어 기본과 한국어 안내. SQLite 누적 저장과 XLSX 보고서 유지

완료 조건은 통제된 시험 환경에서 검색부터 제안·검증·활성화·보고서·재개·한도·실패 처리를 확인하고 기존 테스트가 통과하는 것입니다. 실제로 연결하지 않은 서비스와 실사이트는 미검증으로 명시합니다.

후속 범위는 서비스 설치, 유료 서비스, 내부 자료의 클라우드 모델 전송, 임의 브라우저 동작 계획, 예약 운영, Claude/ChatGPT UI별 배포입니다.
